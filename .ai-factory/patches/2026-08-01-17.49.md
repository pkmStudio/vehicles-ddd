# Queued Excel import serialization with lazy dependencies

Date: 2026-08-01 17:49
Severity: medium
Tags: #php #laravel-excel #queue #serialization #imports

## Problem

The full Laravel test suite failed with `Serialization of 'Closure' is not allowed` while testing queued Excel imports.

Affected import adapters:

- `app/Modules/Vehicles/Features/Import/Infrastructure/Imports/Engine/EngineSparkPlugSpecificationImport.php`
- `app/Modules/Warehouse/Features/Import/Infrastructure/Imports/Nomenclature/NomenclatureImport.php`

## Root Cause

Laravel Excel serializes queued import objects and their event listeners for queued chunk jobs. These import adapters stored container-resolved application services and infrastructure clients as object properties. One of those dependency graphs included a logger/client object containing closures, and `NomenclatureImport` also registered an `AfterImport` closure listener directly.

Queued import adapters must stay serializable between queue dispatch and worker execution.

## Solution

- Removed service/client/repository constructor properties from queued import adapters.
- Resolved required ports lazily inside `collection()`, when the queue worker executes the chunk.
- Replaced the `NomenclatureImport` closure event listener with `[self::class, 'afterImport']`.
- Added `[FIX:queued-import-serialization]` debug logs for import start and completion.
- Added regression tests that serialize the import adapter and registered listeners.

## Files

- `app/Modules/Vehicles/Features/Import/Infrastructure/Imports/Engine/EngineSparkPlugSpecificationImport.php`
- `app/Modules/Warehouse/Features/Import/Infrastructure/Imports/Nomenclature/NomenclatureImport.php`
- `tests/Feature/Vehicles/Import/EngineSparkPlugSpecificationImportTest.php`
- `tests/Feature/Warehouse/Import/NomenclatureImportTest.php`

## Prevention

For any class implementing `ShouldQueue` in Laravel Excel:

- Do not store application services, repositories, clients, loggers, or container-resolved dependency graphs as import object properties.
- Keep constructor state scalar or DTO/value-object only, and verify the object can be serialized.
- Do not use closure listeners in `registerEvents()`.
- Add a serialization regression test for the import object and all registered listeners.

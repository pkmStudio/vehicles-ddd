# Vehicle Wiper Import Allows One Filled Side

**Date:** 2026-08-02 16:29
**Files:** `WiperDetailsBuilder.php`, `WiperDetailsData.php`, `DetailsDataFactoryTest.php`
**Severity:** medium

## Problem

Vehicle wiper import rejected rows where front wipers were filled and rear wipers were empty with:
`Поле «Минимальная длина щётки» обязательно для заполнения.`

## Root Cause

The vehicle wiper details builder always built both `front` and `back` blocks from the 10 Excel
columns. This assumed both sides were mandatory, although the domain allows either side to be
filled independently.

## Solution

The builder now reads fixed-size front and back cell blocks, skips a block when all its cells are
blank, and keeps existing required-field validation when a side is partially filled. If both sides
are blank, the import still fails with the same required-field error.

## Prevention

Cover shared `Templates` details builders with side-specific unit tests for optional nested blocks:
both sides, front-only, back-only, and both blank.

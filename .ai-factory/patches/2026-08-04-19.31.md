# Зафиксировано правило обязательности шаблона brakePads

**Date:** 2026-08-04 19:31
**Files:** tests/Unit/Templates/NomenclatureBrakePadDetailsDataFactoryTest.php
**Severity:** low

## Problem

Для шаблона номенклатуры `brakePads` нужно явно закрепить правило: все поля обязательны, а внутри
размеров должен быть минимум один элемент в каждом измерении: длина, ширина и высота.

## Root Cause

Production-код уже использовал `pullRequiredLabel()` для полей колодок и `pullRequiredIntArray()`
для метрик, но это правило не было покрыто отдельным unit-тестом. Из-за этого при дальнейшей
настройке optional/required для других шаблонов его можно было случайно ослабить.

## Solution

Добавлен unit-тест `NomenclatureBrakePadDetailsDataFactoryTest`: он проверяет успешную сборку
валидной строки и отдельные ошибки при пустых значениях длины, ширины и высоты.

## Prevention

Для каждого шаблона номенклатуры фиксировать обязательность полей тестом после согласования
правил с владельцем домена.

# Зафиксированы required-правила для sparkPlugs и UI wiper

**Date:** 2026-08-04 19:38
**Files:** tests/Unit/Templates/NomenclatureSparkPlugDetailsDataFactoryTest.php, ../dan-center/app/Lists/FieldTemplates/Warehouse/Nomenclature/Templates/WiperTemplate.php, ../dan-center/tests/Unit/Warehouse/Nomenclature/WiperTemplateRequiredFieldsTest.php
**Severity:** low

## Problem

Для шаблонов номенклатуры required-правила уточняются доменно. Нужно было закрепить, что
`sparkPlugs` полностью обязательный, включая минимум по одному значению в длине, ширине и высоте,
а в форме Filament для `wiper` поле `Рулевое управление` должно быть обязательным.

## Root Cause

Parser `sparkPlugs` уже был строгим, но без теста. В UI-шаблоне `wiper` поле `steering` оставалось
nullable, хотя доменное правило требует обязательное значение.

## Solution

Добавлен unit-тест для `sparkPlugs` на все обязательные поля и метрики. В `dan-center`
`WiperTemplate` получил `required: true` для `steering`, добавлен тест на required/nullable
разметку полей формы.

## Prevention

После каждого согласованного шаблона добавлять тест на required/optional правила отдельно для
parser logic и, если форма строится через DSL, для UI-шаблона.

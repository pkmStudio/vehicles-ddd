**Severity:** medium

## Problem

Для номенклатурных шаблонов required-правила уточняются по домену. Масляный, воздушный и салонный
фильтры должны быть полностью обязательными, включая минимум один элемент в каждом размере.
Для щеток длина пассажирской не обязательна, но должна быть заполнена хотя бы водительская или
задняя длина.

## Root Cause

Parser уже был строгим для фильтров, но UI-шаблоны dan-center не везде совпадали с доменным
правилом: `oilFilter` имел nullable-поля, а общий `ArrayField` не превращал required-массивы в
`minItems(1)` для Filament. У wiper parser разрешал одновременно пустые `length_main` и
`length_rear`.

## Solution

В dan-center сделаны required-поля для `oilFilter`, общий `ArrayField` выставляет required и
эффективный `minItems(1)` для обязательных массивов, а `metrics` теперь помечает контейнер
required. В dan-vehicles добавлена проверка `length_main || length_rear` для wiper и unit-тесты
для масляного, воздушного, салонного фильтров и щеток.

## Prevention

Для каждого шаблона после доменного согласования фиксировать оба уровня: parser tests в
dan-vehicles и DSL/UI tests в dan-center. Для cross-field required не ставить фейковую
обязательность на оба поля, а использовать отдельное правило.

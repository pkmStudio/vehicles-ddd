# Исправлена Filament-валидация альтернативных длин wiper

**Date:** 2026-08-04 20:01
**Files:** ../dan-center/app/Lists/FieldTypes/RequiredWithoutNumericField.php, ../dan-center/app/Lists/FieldTemplates/Warehouse/Nomenclature/Templates/WiperTemplate.php, ../dan-center/tests/Unit/Warehouse/Nomenclature/WiperTemplateRequiredFieldsTest.php
**Severity:** medium

## Problem

В Filament-форме щеток поле `Длина задней (мм)` считалось обязательным, даже когда
`Длина водительской (мм)` была заполнена.

## Root Cause

Правило `required_without:details.length_main` выполнялось как raw Laravel validation rule.
Форма `NomenclaturesRest` хранит состояние под `statePath('data')`, поэтому validator искал
`details.length_main`, а фактическое поле лежало в `data.details.length_main`.

## Solution

Для альтернативно обязательных numeric-полей добавлен отдельный Filament field type
`RequiredWithoutNumericField`, который проверяет соседнее поле через `Get`. Filament сам
резолвит путь относительно state path формы, поэтому callback видит фактическое значение
`data.details.*`.

## Prevention

Для cross-field validation в Filament-формах со statePath не использовать raw Laravel
`required_without` с вручную собранными абсолютными путями. Предпочитать `Get` callback или
специализированный field type.

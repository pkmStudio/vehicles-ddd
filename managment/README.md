# Инструкции для менеджеров

Этот раздел описывает работу в Filament после переноса каталогов в `dan-vehicles`.

Главное правило: списки и карточки открываются сразу, а изменения выполняются асинхронно. После нажатия `Создать`, `Сохранить`, `Удалить`, `Импорт` или `Экспорт` система отправляет запрос в обработку. Результат нужно смотреть в уведомлениях Filament.

## Как понимать уведомления

- `Запрос ... отправлен` означает, что действие принято и поставлено в очередь.
- `Запрос ... завершен` означает, что сервис обработал действие.
- Если в уведомлении есть `Открыть файл`, можно скачать экспорт или отчет ошибок.
- Если данные не изменились сразу после сохранения, нужно дождаться уведомления о завершении и обновить страницу.

## Что важно не делать

- Не нажимать одну и ту же кнопку несколько раз подряд, пока не пришло уведомление.
- Не считать изменение сохраненным только по сообщению `Запрос отправлен`.
- Не править TecDoc-поля, если поле закрыто в форме.
- Не запускать повторный импорт, пока предыдущий импорт этого же раздела еще обрабатывается.

# Экспорты

[К инструкциям](README.md) · [Уведомления](notifications.md)

## Как работают экспорты

Экспорт не скачивается сразу. Система отправляет запрос в обработку, формирует файл и присылает уведомление с кнопкой `Открыть файл`.

Порядок общий для всех разделов:

1. Открыть нужный раздел.
2. Нажать кнопку экспорта.
3. Выбрать вариант экспорта, если есть меню.
4. Дождаться уведомления `Запрос на экспорт завершен`.
5. Нажать `Открыть файл`.

## Экспорты транспортных средств

В разделе `Транспортные средства` доступны варианты:

- все машины;
- наши машины;
- двигатели;
- модификации;
- связи модификаций и двигателей;
- применяемость;
- вместе с модификациями;
- вместе со странами.

Использовать:

- `Все машины` для полной выгрузки каталога;
- `Наши машины` для OD-записей;
- `Двигатели` для чистой выгрузки каталога двигателей без свечей и применяемости;
- `Модификации` для массовой проверки и подготовки импорта модификаций;
- `Связи модификаций и двигателей` для массовой проверки связей `mod_id + eng_id + type`;
- `Вместе с модификациями` для проверки машин с модификациями;
- `Вместе со странами` если нужны данные по странам;
- `Применяемость` для выгрузки связки с комплектами.

Файл связей можно использовать как шаблон для удаления связей: убрать лишние строки и загрузить файл обратно через импорт связей.

## Экспорты номенклатуры

В разделе `Номенклатура` экспорт выполняется по категории.

Порядок:

1. Нажать `Выгрузить по категории`.
2. Выбрать нужную категорию.
3. Дождаться уведомления.
4. Открыть файл.

## Экспорты комплектов

В разделе `Комплекты` доступна выгрузка наборов XLSX.

Файл используется для проверки состава, комплектаций, упаковки и расчетных полей.

## Экспорты упаковок

В разделе `Размеры упаковок` доступна выгрузка упаковок XLSX.

Файл используется для проверки габаритов, веса, цены и типа упаковки.

## Экспорты применяемости

Экспорт применяемости формирует файл со связями комплектов и автомобилей.

Перед экспортом применяемости желательно убедиться, что последний расчет завершился успешно.

## Если файл не открывается

1. Проверить, что уведомление именно о завершении, а не только об отправке запроса.
2. Подождать несколько секунд и попробовать снова.
3. Если ссылка все равно не открывается, передать ответственному ID операции из уведомления.

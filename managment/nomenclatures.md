# Номенклатура

[К инструкциям](README.md) · [Комплекты](kits.md) · [Экспорты](exports.md)

## Где находится раздел

Открыть в Filament раздел `Номенклатура`.

Раздел работает через `dan-vehicles`: список читается по REST, а создание, изменение, удаление, импорт и экспорт отправляются в очередь.

## Список

В списке можно:

- искать по названию;
- искать по артикулу производителя;
- фильтровать по бренду;
- фильтровать по типу товара;
- фильтровать по стране;
- создать новую номенклатуру;
- редактировать существующую;
- удалить номенклатуру;
- загрузить импорт;
- выгрузить данные по категории.

## Создание номенклатуры

1. Нажать `Создать`.
2. Выбрать `Тип товара`.
3. Выбрать `Бренд`.
4. Заполнить основные поля.
5. Заполнить дополнительные параметры, которые появились после выбора типа товара.
6. Нажать `Создать`.
7. Дождаться уведомления о завершении.
8. Обновить список и проверить новую запись.

## Основные обязательные поля

Обычно нужно заполнить:

- тип товара;
- бренд;
- название;
- страна;
- артикул производителя;
- цвет;
- вес в граммах;
- количество упаковок;
- количество в упаковке;
- материал;
- вид техники.

Если поле обязательно, Filament не даст отправить форму без него.

## Дополнительные параметры

Дополнительные параметры зависят от типа товара. После выбора типа товара форма показывает нужный набор полей.

Для щеток:

- обязательно рулевое управление;
- должна быть заполнена длина водительской щетки или длина задней щетки;
- длина пассажирской щетки не обязательна;
- адаптеры заполняются, если применимо.

Для колодок:

- обязательны все основные параметры;
- в размерах должна быть минимум одна длина, одна ширина и одна высота.

Для свечей:

- обязательны все основные параметры;
- в размерах должна быть минимум одна длина, одна ширина и одна высота.

Для масляного, воздушного и салонного фильтра:

- обязательны все параметры, которые показывает форма;
- размеры нужно заполнить.

Для адаптеров:

- поле `Конструкция` не используется;
- остальные параметры обязательны.

## Редактирование

1. Открыть номенклатуру через `Редактировать`.
2. Внести изменения.
3. Нажать `Сохранить`.
4. Дождаться уведомления о завершении.
5. Обновить страницу и проверить результат.

## Удаление

Удалять номенклатуру нужно аккуратно: она может использоваться в комплектах и применяемости.

Порядок:

1. Нажать `Удалить`.
2. Подтвердить действие.
3. Дождаться уведомления.
4. Обновить список.

## Импорт

1. Открыть раздел `Номенклатура`.
2. Нажать кнопку загрузки номенклатуры XLSX.
3. Выбрать файл.
4. Подтвердить загрузку.
5. Дождаться уведомления о завершении.
6. Если есть ошибки, открыть XLSX-отчет, исправить файл и загрузить повторно.

Импорт лучше использовать для массовой загрузки. Для одной позиции удобнее форма.

# Размеры упаковок

[К инструкциям](README.md) · [Комплекты](kits.md) · [Экспорты](exports.md)

## Где находится раздел

Открыть в Filament раздел `Размеры упаковок`.

Упаковки используются для расчета комплектов.

## Список

В списке можно:

- искать упаковки;
- фильтровать по типу;
- смотреть габариты, вес, цену и количество комплектов;
- создавать упаковки;
- редактировать упаковки;
- удалять упаковки;
- импортировать упаковки;
- экспортировать упаковки.

## Создание упаковки

1. Нажать `Создать`.
2. Заполнить название упаковки.
3. Заполнить вес.
4. Заполнить высоту, ширину и длину.
5. Заполнить цену.
6. Выбрать тип упаковки.
7. При необходимости отметить `Сгенерирована автоматически`.
8. Нажать `Создать`.
9. Дождаться уведомления.
10. Обновить список и проверить упаковку.

## Что можно менять

Можно менять:

- название;
- вес;
- высоту;
- ширину;
- длину;
- цену;
- тип упаковки;
- признак автоматической генерации.

## Что важно учитывать

Упаковка может быть связана с комплектами. Изменение размеров или веса может повлиять на расчет комплектов.

Если упаковка используется большим количеством комплектов, перед изменением лучше согласовать правку.

## Удаление

1. Нажать `Удалить`.
2. Подтвердить действие.
3. Дождаться уведомления.
4. Обновить список.

Если упаковка используется комплектами, удаление может быть отклонено или привести к необходимости пересчета.

## Импорт упаковок

1. Открыть раздел `Размеры упаковок`.
2. Нажать `Загрузить упаковки XLSX`.
3. Выбрать файл.
4. Подтвердить загрузку.
5. Дождаться уведомления.
6. Если есть ошибки, скачать отчет и исправить файл.

## Экспорт упаковок

1. Открыть раздел `Размеры упаковок`.
2. Нажать `Выгрузить упаковки XLSX`.
3. Дождаться уведомления.
4. Открыть файл из уведомления.

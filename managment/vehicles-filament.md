# Транспортные средства через Filament

[К инструкциям](README.md) · [Импорт ТС](vehicles-import.md) · [Экспорты](exports.md)

## Где находится раздел

Открыть в Filament раздел `Транспортные средства`.

В этом разделе данные показываются из сервиса `dan-vehicles`. Изменения отправляются в обработку через очередь, поэтому после сохранения нужно дождаться уведомления.

## Список

В списке можно:

- искать машины по тексту;
- искать по `ms_id`, если введено число;
- фильтровать по производителю, модели, типу кузова, провайдеру и признаку `Разрешен`;
- открыть создание новой машины;
- открыть редактирование существующей машины;
- удалить машину;
- запустить импорт или экспорт.

## Создание машины

1. Нажать `Создать`.
2. Выбрать марку.
3. Заполнить модель, тип ТС, тип кузова и остальные нужные поля.
4. Поле `ID модели TecDoc` можно оставить пустым.
5. Нажать `Создать`.
6. Дождаться уведомления о завершении создания.
7. Обновить список и проверить новую машину.

Если `ID модели TecDoc` оставить пустым, система создаст собственный отрицательный `ms_id`. Это нормально для наших машин, которых нет в TecDoc.

## Редактирование машины

1. В списке нажать `Редактировать`.
2. Изменить нужные поля.
3. Нажать `Сохранить`.
4. Дождаться уведомления о завершении.
5. Обновить страницу и проверить результат.

## Провайдеры TD и OD

`TD` означает запись из TecDoc. `OD` означает нашу запись.

Для `OD` можно менять бизнес-поля, которые открыты в форме.

Для `TD` часть полей закрыта от изменения. Это защита от случайной правки данных TecDoc. Если поле у `TD` было пустым, его можно заполнить. После заполнения оно останется доступным для дальнейшего редактирования.

## Что можно менять у машины

Обычно можно менять:

- модель;
- транслит;
- поколение и годы поколения, если поле доступно;
- тип ТС;
- тип кузова, если поле доступно;
- рулевое управление;
- признак `Разрешен`;
- параметры деталей;
- модификации и двигатели.

## Что нельзя менять вручную

Нельзя менять поля, которые закрыты в форме:

- `ID модели TecDoc`;
- `ID марки TecDoc`;
- технические поля;
- закрытые поля TecDoc-записей.

Если поле закрыто, его не нужно обходить импортом или повторным сохранением. Для таких случаев нужна отдельная задача.

## Параметры деталей

В секции `Параметры деталей` можно добавлять, редактировать и удалять параметры машины.

Порядок работы:

1. Открыть секцию `Параметры деталей`.
2. Добавить строку или изменить существующую.
3. Выбрать особенность машины, значение особенности и название детали.
4. Заполнить параметры.
5. Нажать `Сохранить`.
6. Дождаться уведомления.

Если строку параметра удалить из формы и сохранить, система отправит запрос на удаление этого параметра.

## Модификации

В секции `Модификации` можно добавлять, редактировать и удалять модификации машины.

При создании новой модификации поле `ID модификации TecDoc` можно оставить пустым. Система создаст собственный отрицательный `mod_id`.

Можно заполнять:

- локализованное название;
- описание;
- годы выпуска;
- мощность;
- количество цилиндров;
- объем двигателя;
- тип двигателя;
- тип КПП;
- тип привода;
- тип тормозной системы.

Технические поля `id`, `vehicle_id` и список разрешенных полей не показываются менеджеру.

## Двигатели внутри модификации

Внутри модификации есть секция `Моторы`.

При создании нового двигателя поле `ID двигателя TecDoc` можно оставить пустым. Система создаст собственный отрицательный `eng_id`.

Можно заполнять:

- код двигателя;
- объем;
- количество цилиндров;
- диаметр цилиндров;
- мощность kw от/до;
- мощность л.с. от/до;
- количество клапанов;
- тип топлива.

Если двигатель удалить из модификации и сохранить, удаляется связь двигателя с этой модификацией. Сам двигатель может остаться в каталоге, если он используется где-то еще.

## Удаление машины

1. В списке нажать `Удалить`.
2. Подтвердить действие.
3. Дождаться уведомления.
4. Обновить список.

Удаление может затронуть связанные данные машины. Перед удалением нужно убедиться, что машина действительно больше не нужна.

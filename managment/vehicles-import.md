# Транспортные средства через импорт

[К инструкциям](README.md) · [ТС через Filament](vehicles-filament.md) · [Уведомления](notifications.md)

## Когда использовать импорт

Импорт нужен, когда нужно массово загрузить или обновить машины и параметры из Excel-файла.

Для точечной правки одной машины лучше использовать форму Filament.

## Как запустить импорт

1. Открыть раздел `Транспортные средства`.
2. Нажать кнопку загрузки импорта.
3. Выбрать XLSX-файл.
4. Подтвердить загрузку.
5. Дождаться уведомления, что запрос отправлен.
6. Дождаться уведомления о завершении импорта.
7. Обновить список и проверить данные.

## Что происходит после загрузки

Файл не обрабатывается мгновенно. Он отправляется в `dan-vehicles`, а обработка идет в очереди.

Пока импорт идет, данные в списке могут быть еще старыми. Проверять результат нужно после уведомления о завершении.

## Что может создать импорт

Импорт может создать или обновить:

- машины;
- параметры деталей машины;
- двигатели;
- модификации;
- связи модификаций с двигателями;
- связи с особенностями;
- данные, которые предусмотрены шаблоном файла.

Если в файле есть новые наши записи без TecDoc ID, сервис может создать собственные отрицательные идентификаторы.

## Импорт двигателей

Импорт двигателей используется только для каталога двигателей. В этом файле больше нет листов свечей и применяемости.

Основные правила:

- новые строки создаются как наши записи `OD`;
- для новой строки `eng_id` можно оставить пустым, тогда сервис создаст отрицательный ID;
- у TecDoc-записей можно менять только поля, которые были пустыми или уже разрешены для ручного изменения;
- попытка изменить закрытое заполненное поле TecDoc попадет в отчет ошибок.

## Импорт модификаций

Импорт модификаций используется только для самих модификаций, без связей с двигателями.

Основные правила:

- `ms_id` обязателен, по нему система определяет машину;
- `type` присваивается автоматически по машине;
- если `type` заполнен в файле и не совпадает с машиной, строка попадет в отчет ошибок;
- для новой нашей модификации `mod_id` можно оставить пустым, тогда сервис создаст отрицательный ID;
- удаление модификаций через Excel на этом этапе не используется.

## Импорт связей модификаций и двигателей

Связи импортируются отдельным файлом с колонками `mod_id`, `eng_id`, `type`.

Одна строка означает одну связь модификации с двигателем. Импорт работает как синхронизация для тех модификаций, которые есть в файле:

- если строку связи убрать из файла и импортировать его, эта связь удалится;
- модификации, которых нет в файле, не меняются;
- `mod_id`, `eng_id` и `type` должны указывать на существующие данные;
- ошибки по неизвестной модификации или двигателю попадут в отчет ошибок.

## Что важно учитывать

- TecDoc import может перезаписывать данные TecDoc.
- Пользовательский импорт нужно запускать только на подготовленном файле.
- Не нужно запускать второй импорт, пока первый еще выполняется.
- Если импорт завершился с ошибками, нужно скачать отчет ошибок и исправлять файл по нему.

## Ошибки импорта

Если часть строк не прошла проверку, придет уведомление с ошибками и кнопкой `Открыть файл`.

В отчете ошибок обычно есть:

- номер строки;
- название листа или раздела;
- текст ошибки;
- данные строки.

После исправления файла можно запустить импорт повторно.

## Когда лучше не использовать импорт

Не стоит использовать импорт для:

- исправления одной машины;
- обхода закрытых полей TecDoc;
- удаления единичного параметра;
- проверки гипотез на рабочих данных.
